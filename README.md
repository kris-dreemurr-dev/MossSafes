# MossSafes 📦🔒

**MossSafes** — легкий и надежный плагин для серверов Minecraft (Spigot / Paper), добавляющий систему кастомных защищенных сейфов на базе обычных и двойных сундуков.

---

## 💡 Ключевые возможности

* **Защита паролем**: Надежная блокировка содержимого сундуков с помощью уникального пароля.
* **Поддержка двойных сундуков**: Автоматическое объединение двух половинок сундука в единый логический сейф.
* **Защита от ошибок при создании**: Система не позволяет объединить сундук в двойной до тех пор, пока на первом блоке не будет завершена регистрация (ввод названия и пароля).
* **Уникальность имен**: Каждый сейф получает индивидуальное название — создание сейфов с одинаковыми именами запрещено.
* **Система 1 попытки**: При неверном вводе пароля сессия ввода моментально сбрасывается для защиты от случайной отправки пароля в публичный чат.
* **Защита с уроном (Ловушка с током)**: Ввод неверного пароля наносит игроку 2.0 единиц урона (1 сердце) и сопровождается звуками удара током.
* **Аудиовизуальный фидбек**:
  * `minecraft:entity.experience_orb.pickup` — при успехе и открытии.
  * `minecraft:block.fence_gate.close` — при попытке открыть чужой сейф.
  * `minecraft:entity.allay.hurt` + `minecraft:entity.bat.death` — при получении урона за неверный пароль.

## 🛠️ Как пользоваться

### 1. Создание сейфа
1. Поставьте предмет сейфа на землю.
2. Напишите в чат **название и пароль через пробел** (например: `my_safe 1234`).
3. Сейф зарегистрирован и готов к использованию!

### 2. Создание двойного сейфа
1. Сначала поставьте первый сундук и полностью зарегистрируйте его (введите название и пароль в чат).
2. Поставьте второй сундук рядом — плагин автоматически расширит сейф до двойного.

### 3. Авторизация и доступ
* Нажмите ПКМ по защищенному сейфу.
* Введите пароль в чат.
* **Если пароль верный**: сундук откроется, а вы автоматически добавитесь в список разрешенных пользователей.
* **Если пароль неверный**: вас ударит током, а сессия ввода закроется. Чтобы попробовать снова, нажмите по сейфу повторно.

---

## ⚙️ Установка

1. Скачайте актуальный `.jar` файл плагина.
2. Поместите его в папку `/plugins/` вашего сервера.
3. Перезапустите сервер. Конфигурационный файл `safes.yml` создастся автоматически.

---

## 📂 Структура данных (`safes.yml`)

Плагин автоматически сохраняет координаты, владельца и список авторизованных игроков:

```yaml
safes:
  world_-24_97_10:
    name: "my_safe"
    password: "1234"
    owner: "d9f2a21f-f8c7-351e-a58e-bf64a8c6e358"
    authorized:
      - "d9f2a21f-f8c7-351e-a58e-bf64a8c6e358"
